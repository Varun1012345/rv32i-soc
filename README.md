\# RV32I SoC



A 32-bit RISC-V RV32I System-on-Chip implemented in SystemVerilog.



\## Tools



\- VS Code

\- Icarus Verilog

\- GTKWave

\- AMD Vivado

\- GitHub



\## Planned Architecture



\- Single-cycle RV32I CPU

\- Register file

\- ALU

\- Program memory

\- Data memory

\- UART peripheral

\- GPIO peripheral

\- FPGA implementation using Vivado

\- ASIC/tapeout-oriented RTL style
